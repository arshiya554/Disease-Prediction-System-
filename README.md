# 🩺 Disease Prediction System

A machine learning-based web application developed using **Python and Flask** that predicts the likelihood of different diseases based on user-provided health parameters.

The system provides a simple web interface where users can enter relevant health information and receive a prediction from the machine learning model.

## ✨ Features

* 🩺 Multi-disease prediction
* 🤖 Machine learning-based predictions
* 🌐 Flask web application
* 👤 User registration and login
* 🗄️ SQLite database for user data
* 📋 Simple and user-friendly interface
* 📊 Prediction based on user-provided health parameters

## 🛠️ Technologies Used

* **Python**
* **Flask**
* **Machine Learning**
* **Naive Bayes**
* **SQLite**
* **HTML**
* **CSS**

## ⚙️ How It Works

1. The user registers or logs into the application.
2. The user selects or provides the required health parameters.
3. The entered information is processed by the application.
4. The machine learning model analyzes the provided data.
5. The system displays the predicted disease/result.
